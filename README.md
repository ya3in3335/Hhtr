# Hhtr — شات بوت ذكاء اصطناعي + لوحة أدمن

تطبيقان منفصلان:

1. **`chatbot/`** — تطبيق الدردشة (PWA) بواجهة حمراء وأيقونات SVG، قابل للتثبيت على الهاتف مع اختصار صوتي سريع كالمساعدات الصوتية.
2. **`backend/`** — الخادم الخلفي + **لوحة الأدمن** حيث يضيف الأدمن **البرومبت الداخلي** للنموذج، ويعمل كوسيط آمن لـ OpenRouter.

> **مهم:** لا يحتوي المشروع على أي برومبت داخلي مسبق. خانة البرومبت في لوحة الأدمن **فارغة بالكامل** افتراضيًا، وما يُرسل للنموذج كـ `system` هو فقط ما يكتبه الأدمن. إذا تُركت فارغة، لا يُرسل أي برومبت نظام إطلاقًا.

## النموذج

يستخدم OpenRouter مع النموذج `poolside/laguna-s-2.1:free` مع تفعيل `reasoning` كما هو مطلوب. يُحقن المفتاح من متغير البيئة `OPENROUTER_API_KEY` ويبقى على الخادم فقط (لا يظهر في الواجهة).

## التشغيل

### 1) الخادم + لوحة الأدمن
```bash
cd backend
cp .env.example .env        # ضع OPENROUTER_API_KEY و ADMIN_TOKEN
npm install
npm start
```
- لوحة الأدمن: `http://localhost:8787/admin` — أدخل `ADMIN_TOKEN`، اكتب البرومبت، احفظ.

### 2) تطبيق الدردشة
قدّم مجلد `chatbot/` عبر أي خادم ثابت:
```bash
cd chatbot
python3 -m http.server 5173
```
- افتح `http://localhost:5173`، ثم من **الإعدادات** اضبط عنوان الخادم الخلفي (مثل `http://localhost:8787`).

> للحصول على المايك/الموقع والـ PWA على الهاتف يلزم HTTPS (أو localhost). انشر `chatbot/` على أي استضافة ثابتة تدعم HTTPS.

## التحكم في الهاتف (بإذن المستخدم)

يُطلب من المستخدم تأكيد إذنين قبل أن يستخدمهما المساعد — ولا يُستخدم أي إذن قبل التأكيد:

1. **المايكروفون / الصوت** — تحدّث للمساعد ويرد صوتيًا (مساعد صوتي).
2. **الموقع** — يقرأ موقعك عند طلبك فقط (مثل: «أين أنا؟»).

تُفعّل من زر الدرع 🛡️ أعلى التطبيق، ويمر كل إذن عبر نافذة صلاحيات المتصفح/النظام. هذه القدرات مبنية على أذونات الجهاز القياسية ومقيّدة بموافقة صريحة — لا تحكم خفيّ أو غير محدود.

## الاختصار الصوتي السريع

عند تثبيت التطبيق (Add to Home Screen) يظهر اختصار **«دردشة صوتية سريعة»** يفتح التطبيق ويبدأ الاستماع فورًا (`?voice=1`).

## ربط GitHub (سريع بدون تعقيد)

من **الإعدادات** → أنشئ توكنًا من `github.com/settings/tokens` والصقه. يُخزَّن محليًا على الهاتف فقط ويُستخدم مباشرة مع `api.github.com` دون المرور بأي خادم آخر.
